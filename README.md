# United Telecom Ventures | Internship Portfolio

## 📌 Overview

This repository documents my internship experience at **United Telecom Ventures, Mumbai**, as a Technical Intern in **ELV Systems & Project Support**.

The internship began on **6 July 2026** and focused on understanding Extra Low Voltage (ELV) systems, project estimation, technical documentation, vendor coordination, and system architecture.

It also explores the connection between ELV infrastructure and **Advanced Digital Forensics**, particularly how security systems generate and preserve digital evidence.

## 🎯 Internship Objectives

- Understand ELV systems, including CCTV, fire alarms, public address, networking, and access control.
- Prepare Bills of Quantities (BOQs), quotations, and technical documentation.
- Study system architecture and design concepts.
- Support vendor communication and technical coordination.
- Develop technical content for company exhibitions.
- Explore the application of digital forensics in ELV infrastructure.

## 🛠️ Areas of Work

| Area | Work Performed |
|---|---|
| CCTV Systems | Studied camera specifications, NVR storage, and CCTV design |
| Access Control | Explored access control systems and their architecture |
| Fire Alarm Systems | Studied fire alarm panels and event logs |
| Networking | Explored IP-based devices, network infrastructure, and connectivity |
| Project Estimation | Worked on BOQs, quotations, rate cards, and Live Estimator |
| Documentation | Maintained trackers, vendor enquiries, and technical records |
| Exhibition Support | Prepared technical descriptions and exhibition content |

## 🔍 Connection with Advanced Digital Forensics

An important aspect of this internship was understanding how ELV systems can serve as sources of digital evidence.

| Forensic Concept | Internship Application |
|---|---|
| Digital Evidence Acquisition | Understanding NVR storage and CCTV footage |
| File System & Data Recovery | Studying NVR storage capacity and overwrite mechanisms |
| Forensic Investigation Tools | Exploring FTK Imager, Autopsy, Wireshark, and ExifTool |
| Network & Email Forensics | Understanding IP device communication and vendor email headers |
| Mobile & Cloud Forensics | Exploring digital traces from mobile applications and cloud-shared documents |
| Evidence Preservation & Reporting | Maintaining BOQs, trackers, documentation, and audit trails |
